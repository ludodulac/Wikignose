# PDF à analyser

Déposer ici les PDF que Wikignose doit analyser et indexer.

Après analyse d’un document, ajouter ou enrichir son entrée dans `../data/wikignose-index.js` et renseigner `file: "pdfs/nom-du-fichier.pdf"`.

Les PDF sont désormais conservés directement dans ce dépôt GitHub : aucun stockage Supabase n’est utilisé par Wikignose.
