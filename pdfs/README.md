# PDF originaux

Ce dossier est réservé aux PDF originaux du corpus Wikignose.

## Règles

- Ne jamais modifier un PDF source lors de l'indexation.
- Conserver le nom de fichier référencé dans `data/index.js`.
- Les extractions de chapitres devront être générées dans un emplacement séparé.
- Si les PDF deviennent trop volumineux pour GitHub, conserver ici un manifeste décrivant leur emplacement de stockage, sans casser les identifiants de l'index.
